# 🎲 Dice Game - React

A simple interactive Dice Game developed using React.js Class Components and Bootstrap 5.

## 📌 About The Project

The Dice Game is a small interactive game where the player tries to find a hidden dice face by rolling the dice.

The game generates a random number between 1 and 6. The player continues playing until finding the hidden face.

## ✨ Features

- 🎲 Roll the dice randomly.
- 🔢 Display the generated dice face.
- 📊 Count the number of attempts.
- 🎉 Display a success message when the hidden face is found.
- 🔄 Restart the game.
- 📱 Responsive design using Bootstrap 5.

## 🛠️ Technologies Used

- React.js
- JavaScript
- Bootstrap 5
- HTML5
- CSS3

## ⚙️ Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd Jeu-De-React
```

3. Install dependencies:

```bash
npm install
```

4. Start the application:

```bash
npm run dev
```

## 🎮 How To Play

1. Open the game.
2. Click on the **Jouer** button.
3. The dice generates a random face between 1 and 6.
4. Try to find the hidden face.
5. When you find it, a success message appears.
6. Click on **Initialiser** to restart the game.
